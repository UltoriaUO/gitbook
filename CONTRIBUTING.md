# Rehber bakımı

Oyuncu içeriği `README.md`, `SUMMARY.md` ve konu dizinlerindedir. Görseller `.gitbook/assets/tr/` altındadır.

Beceri adları İngilizce (Türkçe) biçiminde, büyü isimleri özgün İngilizce yazılır. Örnek fiyatları gerçek oyun fiyatı olarak sunmayın. Büyü açıklamaları oyundaki Türkçe bilgi kutularıyla eşleşmelidir.

Bu depo yalnızca oyuncu rehberini içerir. Sunucu uygulaması, hesap verileri ve özel yapılandırma rehber kaynağının parçası değildir.

GitBook Git Sync için `main` dalını ve proje dizini olarak depo kökünü seçin. Mevcut ve dolu kaynak üzerinden ilk eşitlemede GitHub → GitBook yönünü kullanın; hedef alanda korunması gereken içerik varsa önce onu inceleyin.
