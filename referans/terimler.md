# Ultima Online Türkçe oyun sözlüğü

**Oyundaki İngilizce bir sözcük seni durdurmasın.** Bu sözlükte sık göreceğin adların Türkçe anlamlarını bulabilirsin.

| Sözcük | Kolay açıklaması |
| --- | --- |
| Ultoria | Bu rehberin anlattığı Ultima Online sunucusu |
| Britannia | Maceranın geçtiği oyun dünyasının adı |
| Karakter | Oyun dünyasında yönettiğin kişi |
| NPC | Bilgisayarın yönettiği kişi veya canlı; bankacı buna örnektir |
| Shard | Aynı oyunun ayrı sunucusu ve dünyası |
| Client / İstemci | Oyunu ekranda görmeni ve yönetmeni sağlayan yazılım |
| Skill / Beceri | Karakterinin bir işi ne kadar iyi yaptığını gösteren değer |
| Stat / Nitelik | Güç, çeviklik ve zekâ gibi temel karakter değeri |
| STR / Strength | Güç |
| DEX / Dexterity | Çeviklik |
| INT / Intelligence | Zekâ |
| HP / Hits | Can |
| Stamina | Dinçlik; karakterin hareket ve fiziksel eylem kaynağı. Bazı durum alanlarında dayanıklılık diye de gösterilir |
| Durability | Eşyanın dayanıklılığı veya sağlamlığı; karakterin dinçliğiyle aynı şey değildir |
| Mana | Büyü yaparken kullanılan enerji |
| Backpack / Inventory | Sırt çantası veya eşya taşıma bölümü |
| Paperdoll / Character | Giydiğin eşyaları gösteren karakter penceresi |
| Status | Can ve karakter değerlerini gösteren durum penceresi |
| Journal | Konuşma ve sistem mesajlarını gösteren günlük |
| Gump | Oyundaki bir pencere veya menü |
| Tooltip / Hover | Fareyi eşyanın veya büyünün üzerinde beklettiğinde açılan bilgi kutusu |
| Required Skill | Silahın kullandığı beceri; örneğin Swordsmanship (Kılıç ustalığı) |
| Strength Requirement | Eşyayı kuşanmak için gereken güç |
| Resistance / Direnç | Belirli hasar türüne karşı savunma; büyü direnci becerisiyle aynı değer değildir |
| Charges / Yük | Bir eşyanın veya etkisinin kalan kullanımı |
| Reagent Crystal | Kapsadığı büyü okullarında malzemeleri karşılayabilen, yükü sınırlı malzeme kristali |
| Tithing Points | Chivalry (Şövalyelik) büyülerinde kullanılan bağış puanı; mana ve altın bakiyesinden ayrıdır |
| Mastery / Ustalık | Belirli becerilerin ileri teknikleri; kitabı ve kullanım koşulları bulunur |
| Circle / Çember | Klasik büyü kitabındaki büyü grubu |
| Scroll / Parşömen | Büyü yazılabilen eşya veya parşömen görünümlü arayüz; bağlamına göre farklı anlam taşır |
| Vendor | Satıcı |
| Banker | Bankacı |
| Healer | Şifacı; uygun koşullarda diriltmeye yardım edebilir |
| Target | Hedef; seçmen istenen kişi, eşya veya yer |
| Loot / Ganimet | Yaratık veya macera sonunda alınan eşyalar |
| Craft / Üretim | Malzeme ve araçlarla eşya yapma |
| Reagent | Bazı büyülerde kullanılan malzeme |
| Pet | Sana ait, yönetebildiğin hayvan veya yaratık |
| Mount / Binek | Üzerine binerek hareket edebildiğin uygun canlı |
| Stable | Hayvanların emanete bırakıldığı ahır hizmeti |
| Party / Grup | Birlikte oynayan oyuncuların oluşturduğu küçük ekip |
| Guild / Lonca | Oyuncuların oluşturduğu topluluk |
| PvE | Oyuncunun oyun dünyasındaki yaratıklara karşı oynaması |
| PvP | Oyuncuların birbirine karşı mücadele etmesi |
| Makro | Bir eylemi veya kısa eylem sırasını kısayolla çalıştırma |
| Cooldown | Bir eylemi tekrar kullanmadan önce gereken bekleme |
